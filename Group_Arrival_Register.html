Register Rules

Numeric mode accepts digits only, maximum 3 characters (001–999). Turn this off for room names or letters such as A101 or PH-1.

Pax accepts up to 2 digits. Mobile accepts digits, +, - and spaces, up to 15 characters. All three switches apply immediately.

Manager PIN

Protects Room Master from accidental changes during a shift. This is not security — anyone with browser developer tools can bypass it. Proper accounts arrive with the database backend.
